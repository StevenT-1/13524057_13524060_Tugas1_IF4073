## Deskripsi Program

Program ini merupakan sebuah aplikasi MATLAB berbasis GUI untuk melakukan perbaikan kualitas (image enhancement) terhadap sejumlah citra dengan kualitas visual yang kurang baik. Metode image enhancement yang dapat dilakukan program ini mencakup empat kelompok teknik, yaitu Intensity Transformation, Histogram Equalization, Histogram Specification/Matching, dan Image Filtering dengan Masking.


## Requirements

### MATLAB
- **Version:** R2026a or higher
- **Toolbox:** Image Processing Toolbox

## How to run

```bash
cd src
matlab -r "run('app1.mlapp')"
```
